# Asset credits

SENSORA is an independent fictional fragrance portfolio concept. The three accords describe imagined fragrances.

| Asset | Authorship and distribution |
| --- | --- |
| Bottle profiles, optical shell, liquid, side fluting, sculpted stoppers, collar and direct-to-glass lettering | Original TypeScript geometry and canvas print artwork in `lib/model.ts`. Generated in the browser. |
| Garnet silk, rose petals, pearl orbit, water ribbon, mineral studies and studio environment | Original geometry, shader code and generated studio radiance. No external HDRI, mesh, or texture downloads. |
| SENSORA rosette, wordmark treatment, interface and art direction | Original project artwork based on the owner's SENSORA creative kit. |
| Editorial copy and reference palette | Supplied bilingual project copy and brand tokens. |
| Still image for unavailable WebGL | Edition-specific transparent product stills and a separate silk plate rendered from the original Three.js geometry and shader. |
| Screenshots, cover, Open Graph card and motion preview (`docs/media/`, `public/og.jpg`) | Real captures of this application, composited with its own typefaces. No generated or stock imagery. |
| Bodoni Moda | Bodoni Moda Project Authors, distributed through Fontsource under SIL OFL 1.1. |
| Manrope | Manrope Project Authors, distributed through Fontsource under SIL OFL 1.1. |
| Tajawal | Google Inc., distributed through Fontsource under SIL OFL 1.1. |
| Amiri | Amiri Project Authors, distributed through Fontsource under SIL OFL 1.1. |

Font notices ship in `public/licenses/`. The wordmark and miniature label type also use device serif and sans-serif fonts. The application serves all web fonts locally.

The four supplied satin and perfume images informed fold direction, studio lighting, direct-to-glass lettering and stopper proportions. Their pixels and third-party brand marks are excluded from the runtime artwork. The four owner-supplied inspiration videos, their contact sheets and the review mosaic are study materials. They stay outside the public application bundle. The experience uses no soundtrack.
